# Evidence around a phrase boundary

16 October 2026. This component gives the future interpreter and composer a clearer account of a selected passage. A short estimated note can mean an actual short gesture, a new pluck, a model dropout or a masked ringing note. The raw note list alone cannot distinguish those possibilities.

The component reads a completed instrumental review's retained predictions. The original recording, parent job, candidate events, model predictions and both saved decoder interpretations remain unchanged. No new model inference or sound generation belongs to this check.

## What the report contains

- The exact parent result, original and activation archive identities, model and decoder policies.
- The requested source-sample span, actual surrounding frame bracket and available context, including partial frames and boundaries.
- Unchanged overlapping candidate events from both interpretations, including nearby and octave-related competing pitches.
- Note and onset activations and the relevant contour bins at their stored source anchors. Values remain uncalibrated model outputs.
- Existing decoder threshold predicates as descriptive model evidence, with physical attack, release, performer, instrument and hook identity left unresolved.

The functions are `phrase_boundary_evidence` for supplied in-memory evidence and `load_phrase_boundary_evidence` for a completed Library review. The pure function hashes detached array copies; only the saved-job loader establishes their association with the actual saved archive. The loader binds the expected parent result, protects file identities through a bounded archive read and validates the array geometry before allocation. Requests use absolute source samples and a small explicit set of pitches. An oversized report is refused rather than silently shortened.

## Why this helps the musical work

The retained development control includes an annotated G3 lasting about 1.138 seconds whose estimated event lasts about 0.151 seconds. The annotation and the later model activity provide distinct evidence; neither alone proves how a performer physically released the string. A report around that boundary can expose the dip, later support, onset evidence and competing events that the interpreter needs to consider.

The same representation must preserve a real silent rest, rapid repeated plucks, quiet ambiguous material and octave interference. Automatically extending every short gate, merging nearby notes or choosing the loudest line would hide these counterexamples. This component is a common evidence input for future automatic interpretation and manual review. The required automatic arranger, Essentials focus selection and expressive rendering remain unfinished.

## Validation and resource scope

Eighteen authored controls pass at the root and in independent review, with no failures or skips and resource warnings treated as errors. They cover sustained model activity beyond a candidate ending, true rests, reattacks, harmonic competitors, weak activity, source seams and partial context. Invalid inputs, clocks, archive geometry, excess inflated bytes, cancellation and report overflow refuse while preserving the source data. The archive counterexample includes forged size and prefix-CRC metadata that a conventional ZIP reader alone can accept. These fixtures use authored arrays and temporary Libraries, not retained music.
